## 🚨 应急预案

### 如果12小时内申请不足30人
1. 追加薯条预算到￥300
2. 增加朋友圈发布频次（上午/下午各1次）
3. 私信高意向用户直接邀请
4. 延长招募时间至48小时

### 如果某平台流量异常
1. 立即截图保存数据
2. 分析是否违规
3. 调整文案重新发布
4. 转战备用平台

### 如果服务器压力过大
1. 开启注册限制（每小时10人）
2. 发放排队编号
3. 引导加入等待群
4. 24小时内扩容
