### 2.3 使用指南（文档）

```
📖 小红书AI写作助手 - 快速上手指南

━━━━━━━━━━━━━━━━━━

🚀 第一步：了解你的AI助手

我们的产品有两个核心功能：
• 选题推荐 - 解决"不知道发什么"
• 文案生成 - 解决"不知道怎么写"

━━━━━━━━━━━━━━━━━━

📝 第二步：使用选题推荐

1. 选择你的内容领域（可多选）
   - 美妆护肤
   - 穿搭时尚
   - 生活方式
   - 读书学习
   - 职场成长
   - 美食探店

2. 设置偏好
   - 热门程度：想要追热点还是做常青内容？
   - 难度系数：新手友好还是深度内容？

3. 浏览推荐选题
   - 每个选题都有热度预估
   - 点击"生成文案"直接跳转

━━━━━━━━━━━━━━━━━━

✍️ 第三步：生成文案

1. 输入主题/关键词
   示例："春季口红推荐" "职场通勤穿搭" "读书APP分享"

2. 选择文案风格
   - 干货分享型
   - 种草推荐型
   - 生活记录型
   - 观点表达型

3. 点击生成，等待AI创作

4. 查看生成结果
   - 标题（会生成3个供你选择）
   - 正文（带emoji和话题标签）
   - 封面文案建议

━━━━━━━━━━━━━━━━━━

✨ 第四步：优化和使用

⚠️ 重要提醒：AI生成的是初稿！

建议你做以下优化：
• 加入个人经历和真实感受
• 调整语气，让它更像"你"
• 补充具体的产品名称/使用场景
• 检查事实准确性

然后就可以发布到你的小红书啦~

━━━━━━━━━━━━━━━━━━

💡 进阶技巧

• 多试几次：同一个主题，AI每次生成都不一样
• 组合使用：用A的标题 + B的正文
• 反向优化：把你的旧笔记丢给AI优化

━━━━━━━━━━━━━━━━━━

❓ 常见问题

Q: 生成的文案可以直接发布吗？
A: 不建议。AI是辅助，加入你的个人特色才是好内容。

Q: 为什么生成的内容不够精准？
A: 试试给AI更具体的指令，比如加入你的目标人群、具体场景。

Q: 一天可以生成多少篇？
A: 内测期间不限量，放心用！

━━━━━━━━━━━━━━━━━━

🆘 需要帮助？

• 群里@管理员
• 私信产品反馈
• 发邮件至：feedback@example.com

祝你创作愉快！🎉
```

## 五、常见问题回复话术

### 5.1 功能类问题

**Q: 生成的文案可以直接发布吗？**
```
不建议直接发布哦~

AI生成的是初稿，建议你：
1. 加入个人经历和真实感受
2. 调整语气，让它更像"你"
3. 补充具体的产品名称/细节
4. 检查一遍确保准确性

这样发布的内容既有AI的效率，又有你的个人特色，效果更好！✨
```

**Q: 为什么生成的内容感觉模板化？**
```
这是因为AI在学习和模仿小红书的爆款结构~

解决方法：
1. 给AI更具体的指令（比如目标人群、使用场景）
2. 生成后多加入你的个人风格
3. 尝试不同的关键词组合

我们也在持续优化模型，让生成内容更自然~ 你的反馈很重要！🙏
```

**Q: 可以生成其他平台的文案吗？（如抖音/B站）**
```
目前我们专注于小红书文案优化~

不过你可以：
• 生成小红书文案后，自己调整成其他平台风格
• 关注我们，未来可能会支持其他平台

你想用AI写什么平台的文案？告诉我，我们评估一下需求~ 👀
```

---

### 5.2 账号类问题

**Q: 生成的内容会被判定为抄袭/AI生成吗？**
```
好问题！这确实是大家关心的~

我们的建议：
1. AI生成后一定要人工修改，加入你的个人特色
2. 不要完全照搬，至少要改30%以上
3. 确保内容有你的真实体验和观点

目前小红书对AI内容没有明确的限制政策，但平台肯定更喜欢有真实价值的内容。AI是帮你提效，不是替你创作~ ✍️
```

**Q: 我的账号数据会被泄露吗？**
```
完全理解你的担心！

我们承诺：
✓ 不会收集你的账号密码
✓ 不会擅自发布任何内容
✓ 不会向第三方分享你的数据
✓ 你输入的选题/关键词仅用于生成文案

我们只做内容生成工具，不碰你的账号运营~ 🔒
```
